# Optional DataForSEO workflow

This skill is a provider-specific workflow guide; the plugin does not bundle DataForSEO credentials or an MCP server. First confirm that an authorized DataForSEO connection is already available. Never ask the user to paste an API password into chat or claim to call the service without a working connected tool.

Before a query, specify the endpoint/data type, target location/language/device, number of requests or items, and expected credit/cost estimate if the provider exposes it. Present that estimate and obtain the user's confirmation before spending credits. Use the smallest request that answers the question.

Record provider, retrieval date, parameters, coverage, and returned evidence. Clearly label estimates and snapshots as provider data, not Google guarantees. Do not invent keyword volume, rank, backlinks, map grids, or AI mentions. If connection or cost information is unavailable, stop the paid query and offer a no-cost research alternative with lower/limited precision.
