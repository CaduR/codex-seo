# SEO workflow router

Identify the requested outcome, then use the most specific available skill: `seo-technical`, `seo-page`, `seo-content`, `seo-schema`, `seo-local`, `seo-international`, or `seo-sitemap`. For a broad audit, review only the relevant areas and consolidate findings by impact.

## Working rules

- Ask for a URL or target market only when the request cannot be answered from supplied material.
- Inspect the live page or supplied source before stating that an issue exists. If access is unavailable, label advice as a checklist or hypothesis.
- For each finding, provide evidence, user or search impact, priority, and a concrete fix. Keep verified observations separate from suggestions.
- Prioritize indexing blockers and broken experiences, then high-impact page and content fixes, then refinements. Do not invent ranking guarantees or numerical scores.
- Do not make site changes, submit URLs, or access analytics accounts unless the user requests that action.
- Paid SEO data is optional. State when a recommendation depends on an unavailable source; continue with free evidence where useful.
