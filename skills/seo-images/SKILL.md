# Image SEO

Inspect the page source or supplied asset list. For each meaningful image, consider its purpose, alternative text, descriptive file name, intrinsic dimensions/aspect ratio, responsive `srcset` and `sizes`, format and byte weight, lazy loading, and whether it may be the Largest Contentful Paint image. Decorative images normally use an empty alt attribute. Avoid keyword stuffing and universal alt-length rules.

Distinguish what source inspection establishes from what requires a browser performance trace or field data. Recommend WebP/AVIF only when browser support and visual quality fit the use; preserve fallbacks where needed. Do not lazy-load the likely LCP image by default. Do not claim compressed bytes or CWV improvement without measurement.

For a local conversion request, list destination paths and preserve original assets unless the user explicitly authorizes replacement. For image-result research, explain that live search volume or SERP data may need a paid provider, identify the estimate, and obtain confirmation before querying. AI-generated commerce imagery may have separate platform labeling and metadata rules; verify current requirements before advising publication.

Return findings by image or template, evidence, user/search impact, and a concrete code or editorial fix. This skill does not include a batch image optimizer or paid image SERP connection.
