# Full-site SEO audit

Build a site-wide diagnostic from evidence available in the current session. This skill coordinates review; it does not include a crawler, automated scoring engine, browser farm, or specialist-agent runtime.

## Workflow

1. Confirm the target domain and audit depth. Use a URL the user supplied or ask for one only if absent.
2. Inspect the homepage and a representative set of important pages using available browser, web, or repository tools. Follow robots.txt and avoid high-volume requests. If broad coverage is not possible, say which URLs were reviewed and which were not.
3. Route findings through the relevant installed SEO skills: technical, page, content, schema, local, international, and sitemap. Do not run irrelevant checks or repeat work.
4. Separate observed evidence, supplied metrics, and assumptions. Never infer ranking position, indexing status, field Core Web Vitals, or traffic without a suitable data source.
5. Prioritize blockers first, then high-impact page issues, then editorial and refinement work. Explain impact without promising a ranking outcome.
6. Return an executive summary, scope and evidence, prioritized findings with URL and fix, missing data, and a short next-step plan. Do not invent a numeric health score.

A full audit is a diagnostic. It does not change the site, submit URLs, or access Search Console/analytics unless the user separately requests and enables those actions. Optional providers may have separate costs; identify and confirm paid calls before using them.
