# FLOW SEO workflow

Use FLOW as a lightweight planning lens, not as a ranking formula:

- **Find:** define the audience, intent, page, and evidence gap.
- **Leverage:** identify existing pages, expertise, links, and assets that can support the goal.
- **Optimize:** fix verified technical, content, and page-experience issues.
- **Win:** make the next useful action clear and identify a way to evaluate it.
- **Local:** when the business serves a geography, check accurate business details, local usefulness, and location-specific content.

Select only stages relevant to the request. At each stage, state the evidence, proposed decision, and next action; do not force all stages into a small task. A prompt framework cannot replace current data or subject-matter review. Do not present outcomes as guaranteed or imply affiliation with the source framework. This Codex adaptation is a concise original workflow and does not bundle the Claude SEO contributor's prompt library.
