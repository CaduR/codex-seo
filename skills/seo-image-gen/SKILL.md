# SEO image creation

Start from the page's audience, purpose, brand, aspect ratio, placement, and factual constraints. Propose a concise visual brief and avoid text in the image unless explicitly required. Keep image content relevant to the page; decorative assets do not replace useful page copy or factual product photography.

When an image-generation tool is available and the user requests an asset, follow its image-generation workflow, generate the smallest useful set, and show the result. Do not claim generated images improve rankings. Provide a descriptive file-name suggestion and concise alt text based on the actual image and its page context; use empty alt for purely decorative imagery. Keep source files and output paths clear.

For product, medical, financial, or other factual imagery, do not depict unverified product properties, certifications, or outcomes. Check the destination platform's current labeling/metadata requirements before upload. Generation providers may have separate quotas or costs; disclose them when known. This skill does not bundle an image API or publish assets to a site.
