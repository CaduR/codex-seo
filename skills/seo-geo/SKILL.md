# Generative engine optimization review

Assess whether important information can be retrieved, understood, attributed, and cited. GEO recommendations are hypotheses about clarity and access; no checklist guarantees inclusion in an AI answer.

Review relevant public evidence: robots.txt directives for named crawlers (verify current purpose with the provider), accessible page content, clear entity and author context, direct answers, useful sourcing, consistent facts, page discoverability, and structured data that matches visible content. Review `llms.txt` only as an optional discovery convention, not a Google ranking requirement. Do not equate access for model training with access for search or user-triggered browsing.

For each suggestion, identify the page evidence and intended improvement. Separate crawler access from actual citations or brand mentions. Never claim a citation rate or AI visibility trend without dated observations from a named source. If the user asks for monitoring, specify the provider, dates, geography, and query set needed; ask before paid data calls.

Return the tested URLs, observed access rules, content strengths and gaps, recommendations, and checks that were unavailable. Do not modify robots.txt or publish files without an explicit implementation request.
