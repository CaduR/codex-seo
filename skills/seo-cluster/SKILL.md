# Topic clustering

Start with a seed/topic list, target audience, locale, and site context. Group queries by intent and page purpose using evidence that is actually available. When search-result snapshots are accessible, compare shared ranking URLs and record date, location, device, query, and source. SERP overlap is evidence for review, not a permanent Google intent label. Without SERP data, label the grouping a semantic hypothesis rather than measured clustering.

For each cluster, propose one primary page purpose, supporting questions, a possible hub relationship, and useful internal links. Avoid creating one page per keyword. Check existing pages before recommending new ones and identify cannibalization or consolidation hypotheses only with evidence.

Return the groups, rationale, confidence, pages to reuse/create/merge, and unresolved questions. Search volume and difficulty require a suitable data source and can be paid; do not invent metrics. This skill does not provide an automated clustering pipeline or interactive graph.
