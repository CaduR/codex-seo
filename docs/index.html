// FAQ

Perguntas diretas.

É idêntico ao Claude SEO?

Reproduz as 26 áreas de workflow e os principais materiais de referência, adaptados ao Codex. A interface de comandos, runtime e integrações específicas do Claude não são iguais: o Codex usa skills e um servidor MCP local. A paridade com APIs de terceiros depende de conexões autorizadas.

O plugin rastreia 500 páginas automaticamente?

Não. O MCP padrão inspeciona páginas individuais, descobre sitemaps e executa verificações de leitura. Um crawler completo e paralelismo automático de 17 especialistas não estão implementados.

As 19 funções de especialista são agentes instaláveis?

São cartões de papel para guiar análises delegadas ou inline. A delegação paralela depende das ferramentas que a sessão Codex disponibilizar; o pacote não instala 19 agentes independentes.

Precisa pagar por API?

Não. Nenhuma API paga é obrigatória. DataForSEO, Ahrefs, Firecrawl e outras extensões não estão conectadas no MCP padrão; consulte o guia de extensões antes de configurar provedores.

O que o setup instala?

Pacotes Python open source em um ambiente isolado na pasta de dados do usuário. Chromium é opcional. O setup não conecta contas SEO nem envia dados de analytics.
