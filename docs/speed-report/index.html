LABORATÓRIO

Lighthouse

Uma execução de laboratório diagnostica uma visita simulada sob condições controladas. O resultado pode mudar entre execuções e não representa por si só a experiência de campo.

DADOS DE CAMPO

CrUX

Core Web Vitals de campo dependem de dados reais e amostra suficiente. Um resultado ausente não significa aprovação nem reprovação.

SEM RANKING FABRICADO

REPRODUÇÃO

Guarde o contexto

Ao compartilhar um resultado, registre URL, data, dispositivo, modo de teste e se o dado é de laboratório ou de campo.

// COMO REPRODUZIR

Um procedimento comparável.

  1. Abra o PageSpeed Insights no link acima.
  2. Registre uma medição mobile e uma desktop; anote a data e a URL.
  3. Se repetir o teste, mantenha condições iguais e reporte cada execução ou a mediana, identificando o método.
  4. Separe Lighthouse de laboratório dos dados CrUX de campo e não trate score como ranking de busca.

Os resultados ao vivo pertencem ao PageSpeed Insights; esta página não coleta nem armazena seus testes.
