Pronto para
começar?

Adicione o marketplace, instale o plugin e confira o runtime local. A instalação não conecta contas externas.

ADICIONE O MARKETPLACEcodex plugin marketplace add CaduR/codex-seo

Requisitos

  • Codex Desktop com execução local de plugins habilitada.
  • Python 3.11–3.14 disponível pelo comando python.
  • Git para adicionar o marketplace do GitHub.

As skills ficam disponíveis como instruções. As ferramentas MCP locais também precisam do runtime Python.

Instalar

  1. Adicione o marketplace pelo comando acima.
  2. No Codex Desktop, abra Plugins, selecione Codex SEO e instale.
  3. Inicie uma conversa nova e execute $seo_doctor para conferir o runtime.
  4. Se o diagnóstico indicar que falta configuração, execute $seo_setup. As dependências Python são instaladas em um ambiente isolado na pasta de dados do usuário. Chromium é opcional.

Conferir

Peça um workflow de página pública, como $seo-page https://example.com. Confira as evidências encontradas, os limites e as fontes de dados indisponíveis. $seo_doctor verifica o runtime sem fazer alterações.

O que a configuração altera

O setup cria um ambiente virtual, instala os pacotes de requirements.txt e grava o estado do runtime na pasta de dados do usuário. Chromium é um download separado, opcional, para páginas renderizadas com JavaScript e capturas de tela.

Limites

O servidor MCP local oferece apenas ferramentas de análise e leitura. Consultas a dados de contas, consumo de créditos, envio de URLs e gravação de arquivos do usuário não estão disponíveis por essa ferramenta genérica. Conectores externos exigem configuração e autorização próprias.
