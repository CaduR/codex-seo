SEO content brief

Confirm the topic, audience, geography, business goal, and existing related pages. Identify a primary reader question and supporting needs. If current search results are available, record the query, locale, device, date, and observed formats; otherwise label intent and competitor coverage as hypotheses. Never imply a SERP review occurred without evidence.

Create a usable brief with: page purpose and audience; proposed title/slug direction; intent; key questions to answer; outline and section purpose; facts, examples, or original expertise to collect; internal-link destinations to verify; calls to action; and editorial/source checks. Include only relevant requirements, not a keyword quota. Flag overlap with known existing pages and distinguish evidence gaps from writing choices.

Do not fabricate statistics, credentials, citations, quotes, or product capabilities. Avoid templated outlines that create near-duplicate pages. Return concise acceptance criteria a human editor can verify. This skill does not automatically scrape SERPs, create a competitive dataset, or publish a page; those require available tools and explicit scope.

// LIMITES

O que esperar

As recomendações devem ser ligadas a evidências observadas. Se uma página, conta ou fonte de dados não estiver acessível, o resultado precisa indicar essa limitação.

Dados do Google, backlinks, posições e buscas atuais não são presumidos. Conexões de terceiros podem exigir conta, permissão e custos próprios.
