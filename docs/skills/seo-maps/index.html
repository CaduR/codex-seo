Maps intelligence

A map result changes by location, language, device, time, and query. Never present one search result or a guessed position as a representative geo-grid ranking.

First define the business, verified locations/service areas, target queries, grid center and radius, language, device, and observation date. Prefer user-provided exports or a configured maps/SEO provider. If no geo-grid source is available, provide a manual research plan and label it clearly; do not fabricate coordinates, rank positions, profile fields, review counts, or competitor distances.

Analyze valid observations for coverage patterns, nearby competitors, profile completeness, review themes, and location-specific opportunities. Avoid recommending fake addresses, keyword-stuffed business names, incentivized reviews, or unauthorized edits to a Business Profile. Mark sparse or stale samples and explain their limits.

Report source and date, query and location parameters, observed results, confidence/coverage gaps, and practical actions. Provider APIs may cost money and require credentials. Before any paid query, state the provider, expected charge or credit use if available, and wait for user confirmation. This skill does not itself connect to a maps API or track positions over time.

Dados do Google, backlinks, posições e buscas atuais não são presumidos. Conexões de terceiros podem exigir conta, permissão e custos próprios.
