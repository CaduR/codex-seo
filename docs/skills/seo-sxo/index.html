Search experience optimization

Search experience optimization

Review the target page, intended audience, query, and any dated search results the user provides or the available tools can access. Describe observed result formats and likely intent separately from assumptions. Do not treat a SERP snapshot as stable or universal; record locale, device, and date when known.

Compare the page's format, promise, content depth, trust evidence, navigation, mobile usability, and next action with the task a visitor appears to have. Identify friction with concrete examples. Use personas only as explicit lenses, not as fabricated user research. Suggest testable changes and, where useful, variants for an experiment.

Return evidence, audience task, mismatch/friction, proposed change, and a way to evaluate it. Do not assign a pseudo-scientific conversion score or forecast a ranking/conversion lift. Live SERP datasets may require a paid provider; estimate and obtain approval before paid calls. This skill does not change the page or run an A/B test.

O que esperar

As recomendações devem ser ligadas a evidências observadas. Se uma página, conta ou fonte de dados não estiver acessível, o resultado precisa indicar essa limitação.

Dados do Google, backlinks, posições e buscas atuais não são presumidos. Conexões de terceiros podem exigir conta, permissão e custos próprios.
