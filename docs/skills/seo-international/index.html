International SEO review

Map the supplied language and country URL variants. Check hreflang language/region codes, reciprocal references, self-references, absolute URLs, canonical alignment, and whether each target page exists and serves the intended language. Review language selectors and localized metadata/content where available.

Report exact URL pairs and errors. Distinguish language targeting from country targeting; do not assume every language needs a separate country variant. Draft tags only from confirmed URL mappings, and flag missing mappings rather than inventing them.

// LIMITES

O que esperar

As recomendações devem ser ligadas a evidências observadas. Se uma página, conta ou fonte de dados não estiver acessível, o resultado precisa indicar essa limitação.

Dados do Google, backlinks, posições e buscas atuais não são presumidos. Conexões de terceiros podem exigir conta, permissão e custos próprios.
