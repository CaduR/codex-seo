Programmatic SEO planning

Treat every proposed URL as a user-facing page that must have a distinct purpose and dependable source data. Review the query demand hypothesis, page template, unique data fields, source ownership/freshness, internal links, URL rules, indexability, and maintenance plan.

Before recommending scale, examine representative records and rendered examples. Flag pages that merely swap a city/product name, repeat thin copy, contain empty fields, make unsupported claims, or have no standalone value. Propose quality gates such as minimum required verified data, unique usefulness, valid canonical/robots decisions, and editorial sampling; these are project safeguards, not Google thresholds.

Return a sample page outline, data contract, URL/template notes, risks, and a small review-first rollout. Do not generate or publish hundreds of URLs without explicit scope and approval. A sitemap is not a substitute for quality. This skill has no crawler, CMS writer, or automatic indexing prediction; implementation needs verified data and human review.

O que esperar

As recomendações devem ser ligadas a evidências observadas. Se uma página, conta ou fonte de dados não estiver acessível, o resultado precisa indicar essa limitação.

Dados do Google, backlinks, posições e buscas atuais não são presumidos. Conexões de terceiros podem exigir conta, permissão e custos próprios.
