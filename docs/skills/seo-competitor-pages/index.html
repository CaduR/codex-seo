Competitor comparison pages

Create comparison content that helps a reader make a fair, informed choice. Start by confirming the products, audience, decision criteria, and what evidence the user can provide. Use current official product documentation or user-supplied materials for feature and pricing claims. If facts cannot be verified, mark them for confirmation instead of guessing.

Choose a page format only when it fits the query and available evidence: side-by-side comparison, alternatives overview, or focused feature comparison. Make criteria consistent across products, distinguish facts from editorial judgment, show meaningful trade-offs, and disclose the publisher's relationship to the compared brands where relevant. Do not fabricate competitor shortcomings, reviews, benchmarks, customer counts, or quotes.

Return a proposed URL/page structure, comparison matrix, source checklist, draft copy when requested, and outstanding facts to verify. Avoid doorway pages and near-duplicate permutations. This skill does not fetch a live SERP or competitor database by itself; current pricing and product details need authoritative sources.

O que esperar

As recomendações devem ser ligadas a evidências observadas. Se uma página, conta ou fonte de dados não estiver acessível, o resultado precisa indicar essa limitação.

Dados do Google, backlinks, posições e buscas atuais não são presumidos. Conexões de terceiros podem exigir conta, permissão e custos próprios.
